# The Long Roast: Lawmakers and the File They Cannot Convert

A single satirical sentence roasting lawmakers who would regulate AI, crypto, and the internet — but cannot convert a Word file to PDF.

## Entry

> They can regulate artificial intelligence, cryptocurrency, and the entire internet, but ask them to convert a Word file to PDF and the only thing that gets converted is their confidence — into a call to IT.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the entry text to `/output/entry.txt`.

```sh
python3 main.py
```
